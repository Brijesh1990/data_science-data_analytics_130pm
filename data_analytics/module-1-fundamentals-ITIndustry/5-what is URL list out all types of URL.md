# What is a URL?

A URL (Uniform Resource Locator) is the address used to locate a resource on the internet, such as a webpage, image, file, or document. It tells the browser where to find the resource and how to access it.

## Definition
A URL is the web address of a resource on the internet.

## Parts of a URL
A typical URL has the following parts:
- Protocol: Indicates how the resource is accessed, such as http or https
- Domain name: The website name, such as example.com
- Path: The specific page or file location
- Query string: Extra information sent to the server
- Fragment: A section inside a webpage

## Example of a URL
https://www.example.com/products/item1?category=books#details

### Breakdown
- https:// -> Protocol
- www.example.com -> Domain name
- /products/item1 -> Path
- ?category=books -> Query string
- #details -> Fragment

## Types of URL

### 1. Absolute URL
A complete web address that includes the protocol and domain name.
Example: https://www.example.com

### 2. Relative URL
A URL that is relative to the current page or directory.
Example: /about.html

### 3. Dynamic URL
A URL that contains parameters and changes based on user input or database values.
Example: https://www.example.com/products?id=10

### 4. Static URL
A URL that does not change and is usually simple and readable.
Example: https://www.example.com/about

### 5. Canonical URL
The preferred version of a URL used to avoid duplicate content issues in SEO.
Example: https://www.example.com/about

### 6. Permanent URL (PURL)
A URL that is intended to remain stable over time.
Example: https://www.example.com/blog/seo-basics

### 7. Temporary URL
A short-lived URL used for a temporary purpose.
Example: https://temp.example.com/offer

### 8. URL with Query Parameters
A URL that includes extra values passed to the server.
Example: https://www.example.com/search?q=python

## Importance of URL
- Helps users locate websites and pages
- Helps browsers find resources quickly
- Used by search engines for indexing
- Important for website navigation and SEO

## Conclusion
A URL is the address of a resource on the internet. It helps users and browsers find the correct page or file by providing the necessary location details.
